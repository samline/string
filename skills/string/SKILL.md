# @samline/string

Build against the installed version; this skill describes 2.0.1.

- **Install:** `npm install @samline/string`. Plain HTML: load `https://cdn.jsdelivr.net/npm/@samline/string@2.0.1/dist/browser/string.global.js` and use `window.Strings`.
- **Identifiers:** `camelCase`, `pascalCase`, `kebabCase`, `snakeCase`, `dotCase`, `pathCase`, `constantCase`, `trainCase`. They split with `words()` (separators, camelCase, acronyms like `XMLHttp`, any script) and keep accents.
- **Human text:** `titleCase(text, { smallWords })`, `sentenceCase`, `capitalize`, `uncapitalize`.
- **Slugs:** `slugify(text, { separator, lower, replacements, maxLength, trim, locale, charMap, preserve })`. Use `{ trim: false }` while the user types and a plain `slugify()` for the final value. `replacements` takes an object (literal) or `[RegExp | string, string]` pairs. `charMap: CYRILLIC | GREEK | GERMAN` (or a merged/custom map) for other scripts. `uniqueSlug(text, taken)` → first free slug (`hola-3`); exclude the edited record's own slug from `taken`. HTML: `data-string-taken='["a","b"]'`, `data-string-transliterate="cyrillic, greek"`, `data-string-preserve="."`. `removeAccents(text, { charMap })` for accent-insensitive search.
- **Display:** `truncate(text, length, { ellipsis, wordBoundary, position })` counts graphemes, so emoji and accents are never split; `position: 'middle'` for file names and IDs, `'start'` to keep the ending. `initials(text, { max })`.
- **Text:** `graphemes` (user-perceived characters; `truncate` and `initials` count them), `wordCount`/`readingTime(text, { wordsPerMinute })` via `Intl.Segmenter`, `pluralize(count, { zero?, one, few?, many?, other }, { locale, ordinal })` with `#` for the formatted count, `template('Hola {user.name}', values, { missing })`, `escapeHtml`, `unescapeHtml`, `stripTags` (plain text, not a sanitizer). Do not hand-roll `count === 1 ? … : …` plurals.
- **By name:** `convert(text, to, options)` with `to` from `CONVERSIONS` (`camel`, `kebab`, `slug`, `truncate` + `length`, `initials`…); `isConversion(value)` validates user input.
- **Search:** `fold`, `contains(text, query)` (accent/case-insensitive, every word must appear), `highlight(text, query)` → `[{ text, match }]` pieces of the original text (build marks with `textContent`, never innerHTML), `compareNatural` for `.sort()` (`file2` < `file10`), `distance`, `similarity`, `closest(input, candidates, { threshold })` for "Did you mean". List filter: `<ul data-string-search="#q">` hides non-matching children, wraps matches in `<mark>`, shows a `[data-string-search-empty]` child, emits `string:search` with `{ query, matches, total, state }`.
- **More HTML behaviors:** `<output data-string-count="#bio">` (remaining graphemes from `maxlength`, `-unit="words"`, `-format="{remaining} left"`, state `ok|near|over`, event `string:count`); `<span data-string-fit style="display:block">file.pdf</span>` (middle-cut to the box width, refits on resize; needs a width); `<button data-string-copy="#name" data-string-copy-as="slug">` (state `copied|error`, event `string:copy`; falls back to a selection copy without the Clipboard API); `data-string-color` sets `--string-color` for avatars (`hashColor(text)` in code). Browser bundle starts all; `Strings.auto({ count, fit, copy, search })` for per-behavior options.
- **HTML:** `import { string, autoString } from '@samline/string/vanilla'`, or the CDN bundle, which auto-inits (`data-manual` + `Strings.auto()` to start manually). `data-string="<conversion>"` on any element; options as `data-string-<option>` (`-source`, `-length`, `-position`, `-small-words`, `-replacements` as JSON, `-locale`…), attributes win over options. Fields convert while typing and finalize on blur. A slug field: `<input data-string="slug" data-string-source="#title">` follows until edited (`data-string-state="following" | "edited"`), follows again when emptied. Listen to the `string:change` event; `destroy()` restores markup. Do not hand-write slug-follow listeners.
- **Locales:** pass `{ locale: 'tr' }` (or any BCP 47 tag) where casing depends on language.
- **Do not** write ad-hoc regex case conversions or slug code beside it; every function is pure and safe on the server.
