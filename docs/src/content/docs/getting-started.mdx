Install `@samline/string`, then follow the Package / ESM or the HTML / CDN path to the first slug. Both use the same API.

## Requirements

- Any modern browser, Node 20 or newer, workers and edge runtimes. The functions never touch the DOM; the optional HTML layer needs one and does nothing without it.
- No runtime dependencies.

## Install

<Installer />

## Package / ESM

```js
import { camelCase, slugify, truncate } from '@samline/string'

camelCase('user_first_name') // 'userFirstName'
slugify('¡Hola, Ñandú & Café!') // 'hola-nandu-cafe'
truncate('The quick brown fox', 12) // 'The quick…'
```

Every function is tree-shakeable and available from ESM and CommonJS (`require('@samline/string')`).

## HTML / CDN

For Shopify, WordPress or plain HTML pages without a build step, load the browser bundle with a classic script tag. Pin the version in production.

```html
<script src="https://cdn.jsdelivr.net/npm/@samline/string@1.4.0/dist/browser/string.global.js"></script>
<script>
  const { slugify, titleCase } = window.SamlineString
</script>
```

The bundle also converts every element with a `data-string` attribute, for example `<input data-string="slug" data-string-source="#title" />`. See [HTML attributes](../guides/html/).
