`@samline/string` converts text between cases, builds URL slugs, searches without accents and shapes text for display, from code or straight from HTML attributes. Every function relies on the same word splitter, so `XMLHttpRequest`, `xml-http-request` and `xml_http_request` always agree.

| Job                 | Functions                                                                                                            |
| ------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Identifiers         | `camelCase`, `pascalCase`, `kebabCase`, `snakeCase`, `dotCase`, `pathCase`, `constantCase`, `trainCase`              |
| Human text          | `titleCase`, `sentenceCase`, `capitalize`, `uncapitalize`                                                            |
| URLs and accents    | `slugify`, `uniqueSlug`, `removeAccents`, `CYRILLIC`, `GREEK`, `GERMAN`                                              |
| Display             | `truncate`, `initials`, `graphemes`, `hashColor`                                                                     |
| Text                | `wordCount`, `readingTime`, `pluralize`, `template`, `escapeHtml`, `unescapeHtml`, `stripTags`                       |
| Search              | `fold`, `contains`, `highlight`, `compareNatural`, `distance`, `similarity`, `closest`                               |
| Conversions by name | `convert`, `CONVERSIONS`, `isConversion`                                                                             |
| HTML (`/vanilla`)   | `data-string`, `data-string-search`, `data-string-count`, `data-string-fit`, `data-string-copy`, `data-string-color` |
| Building blocks     | `words`                                                                                                              |
